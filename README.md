# 🎮 C Mini Games Collection

Welcome to my **C Mini Games Collection**!
This repository contains a collection of simple and interactive games developed using the **C programming language**.

These projects were created to practice programming fundamentals, improve logical thinking, and understand how basic C concepts are used in real programs.

## 🎯 Games Included

### 1. ✊ Rock Paper Scissors

A classic Rock Paper Scissors game where the player competes against the computer.

**Concepts Used:**

* `if-else`
* `switch`
* Random numbers
* User input
* Conditional logic

### 2. 🧠 Quiz Game

A simple quiz game that asks the player multiple-choice questions and calculates the final score.

**Concepts Used:**

* Variables
* `if-else`
* `switch`
* Arrays
* Loops
* User input
* Score calculation

### 3. 🔢 Number Guessing Game

The computer generates a random number, and the player has to guess it.

The program gives hints such as whether the guessed number is **higher or lower** than the target number.

**Concepts Used:**

* Random number generation
* `if-else`
* Loops
* User input
* Comparison operators

## 🚀 How to Run

### Step 1: Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### Step 2: Open the project folder

```bash
cd C-Mini-Games
```

### Step 3: Compile a program

For example:

```bash
gcc rock_paper_scissors.c -o game
```

### Step 4: Run the program

```bash
./game
```

For Windows:

```bash
game.exe
```
